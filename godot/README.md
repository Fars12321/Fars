# GodWorld — Godot Edition

نسخة Godot 4 من عالم الآلهة، موجهة للمتصفح أولاً.

## الحلقة الأساسية
- اختر بطاقة سلالة واحدة.
- ضعها على الخريطة.
- السكان ينمون ويهاجرون ويتكيفون مع البيئة.
- خمس ممالك تبدأ من تلقاء نفسها وتتطور.
- موارد، ذهب، إيمان، تقنية، أحداث تاريخية، وقرارات إلهية.

## التشغيل محليًا
افتح مجلد `godot/` في Godot 4.7.2 أو أحدث.

## Railway
Railway يبني المشروع باستخدام Godot headless ثم يصدر نسخة Web ويقدمها عبر nginx. Railway ليس سطح مكتب Godot تفاعليًا؛ المحرك يعمل داخل مرحلة البناء والتصدير.

Build target: Godot 4.7.2 / Web / Compatibility / single-threaded.
