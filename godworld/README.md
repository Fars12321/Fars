# GodWorld v15 — Autonomous Rebuild

هذا الإصدار لا يعتمد على تدخل اللاعب كي تظهر الحياة. يبدأ العالم تلقائيًا ثم تتحرك الحضارات، السكان، الموارد، المدن والجيوش مع الزمن.

## ما تم بناؤه
- World Renderer طبقي: أرض + طرق + حدود + طبيعة + موارد + مبانٍ + سكان + جيوش.
- 4 حضارات بسمات مختلفة واقتصاد وتقنية ومعنويات.
- مدن ترتقي تلقائيًا من مستوى إلى مستوى وتضيف مباني وسكانًا.
- سكان أفراد وحيوانات وحركة مستمرة.
- حروب وجيوش وحساب قوة/معنويات وتراجع/انتهاء الحملات.
- Touch pan + pinch zoom مع انتقال سلس من إصبعين إلى إصبع.
- Pixel-art atlas أصلي متعدد العناصر بدل الأشكال البدائية.
- Smoke test يعمل تلقائيًا عبر GitHub Actions باستخدام Godot 4.7.2.

## اختبار تلقائي
الـCI يشغل المشروع Headless، يحمّل المشهد، يترك المحاكاة تعمل لعدة مئات من الإطارات، ثم يتحقق من وجود الحضارات والسكان والمباني والطبيعة وتقدم عمر العالم.

لا أعتبر ZIP صالحًا لمجرد أن ضغطه سليم؛ نجاح الإصدار يعني نجاح اختبار Godot نفسه.
